# Java Internship Projects

A collection of Java-based projects developed as part of my internship. These projects demonstrate practical implementation of Core Java concepts, Object-Oriented Programming, input validation, exception handling, collections, and modular application design.

## Projects

### 1. Number Guessing Game

A console-based Java game where the user attempts to guess a randomly generated number within a specified range.

**Features**
- Random number generation
- Easy, Medium, and Hard difficulty levels
- Limited attempts
- Higher/Lower hints
- Score calculation
- Multiple rounds
- Input validation

**Concepts Used**
- Random
- Scanner
- Methods
- Loops
- Conditional statements
- Exception handling

---

### 2. Grade Calculator

A Java application that accepts subject names and marks and generates a complete result summary.

**Features**
- Multiple subject input
- Marks validation
- Total marks calculation
- Average percentage
- Grade calculation
- Pass/Fail status
- Formatted result sheet

**Concepts Used**
- Arrays
- Methods
- Conditional statements
- Loops
- Exception handling
- Formatted output

---

### 3. ATM Interface

An object-oriented ATM simulation that provides common banking operations through a menu-driven interface.

**Features**
- User account setup
- PIN authentication
- Balance inquiry
- Deposit money
- Withdraw money
- Daily withdrawal limit
- Transaction history
- Mini statement
- Input validation

**Concepts Used**
- Classes and Objects
- Encapsulation
- Constructors
- Inheritance-free modular OOP design
- ArrayList
- Enum
- Exception handling
- Java Date and Time API
