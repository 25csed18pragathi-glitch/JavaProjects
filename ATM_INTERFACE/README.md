# ATM Interface

A Java-based ATM simulation developed using Object-Oriented Programming principles. The application provides common ATM operations through a secure, menu-driven interface.

## Features

- Account setup
- PIN authentication
- Balance inquiry
- Deposit
- Withdrawal
- Insufficient balance validation
- Daily withdrawal limit
- Transaction history
- Mini statement
- Input validation
- Date and time tracking
