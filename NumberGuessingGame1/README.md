# Number Guessing Game

A console-based Java application where the user tries to guess a randomly generated number between 1 and 100.

## Features

- Random number generation
- Three difficulty levels
- Limited attempts
- Higher/Lower hints
- Score calculation
- Multiple rounds
- Input validation

## Difficulty Levels

| Level | Attempts |
|-------|----------|
| Easy | 10 |
| Medium | 7 |
| Hard | 5 |

## Technologies

- Java
- Core Java
- Random
- Scanner

## How to Run

```bash
javac NumberGuessingGame.java
java NumberGuessingGame
