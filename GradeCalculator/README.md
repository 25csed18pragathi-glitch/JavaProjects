# Grade Calculator

A Java console application that accepts marks for multiple subjects and generates a complete academic result.

## Features

- Accepts subject names
- Accepts marks from 0 to 100
- Validates user input
- Calculates total marks
- Calculates average percentage
- Assigns grades
- Displays Pass/Fail status
- Generates a formatted result sheet

## Grade System

| Percentage | Grade |
|------------|-------|
| 90 - 100 | A+ |
| 80 - 89 | A |
| 70 - 79 | B |
| 60 - 69 | C |
| 50 - 59 | D |
| 40 - 49 | E |
| Below 40 | F |

## Technologies

- Java
- Arrays
- Methods
- Exception Handling

## How to Run

```bash
javac GradeCalculator.java
java GradeCalculator
